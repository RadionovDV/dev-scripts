Экспорт пропов Roblox → JSON

Файлы:
  props_roblox_to_json.lua        — код для Command Bar Roblox Studio.
  props_roblox_to_json_start.ps1  — помощник с окном сохранения Windows.
  props_roblox_to_json_start.cmd  — запуск помощника двойным щелчком.

Как запустить:
1. Сохраните все файлы в одной папке.
2. Дважды щёлкните props_roblox_to_json_start.cmd. Оставьте его окно открытым.
3. В Roblox Studio включите Allow HTTP Requests:
   File → Experience Settings → Security.
4. Остановите Play. Выделите ровно одну Folder или Model.
5. Откройте props_roblox_to_json.lua в текстовом редакторе, скопируйте весь
   текст и выполните его в Command Bar Roblox Studio.
6. В окне «Save Roblox props as JSON» выберите папку и имя файла.
   Итоговый путь и количество пропов появятся в Output.
7. Помощник можно оставить для следующих экспортов. Чтобы остановить его,
   нажмите Ctrl+C в его окне.

Что сохраняется:
  Только непосредственные дети выделенного контейнера: Model и BasePart,
  включая MeshPart. Другие типы пропускаются с warn и ссылкой на объект.
  Вложенные детали читаются для цветов и определения масштаба, но не
  становятся самостоятельными записями JSON.
  Позиции — мировые координаты pivot.
  rotation — поворот относительно шаблона, в формате x/y/z/w.
  size — множители масштаба по осям шаблона.
  color — имена деталей и их Color в формате #RRGGBB.
  Пустой контейнер сохраняется как [].

Шаблоны:
  Нужна папка Assets в ServerStorage. Поиск шаблонов по имени совпадает
  с props_json_to_roblox.lua. Имена пропов должны совпадать с шаблонами.
  У шаблонов и их деталей должен быть включён Archivable.
  Проверка на временной копии убеждается, что импортёр сможет восстановить
  положение, поворот и размеры деталей. При несовместимом изменении
  геометрии экспорт останавливается с ошибкой и ссылкой на проп.
  Временные копии не добавляются в сцену и удаляются после проверки.

Имена и цвета:
  Совпадение цветов разрешено и не проверяется.
  Повтор имени детали внутри одного пропа вызывает warn со ссылками
  на первое и повторное вхождения. В color остаётся первое вхождение.
  Повторяющиеся имена самостоятельных пропов разрешены.
  Материалы, текстуры, MeshId и остальные свойства не экспортируются:
  при импорте они берутся из шаблона.

Помощник:
  Работает только на этом компьютере: http://127.0.0.1:28743.
  Права администратора и установка библиотек не нужны.
  Поддерживаются Windows PowerShell 5.1 и PowerShell 7 на Windows.
  JSON записывается с отступами, в UTF-8 без BOM; точность чисел сохраняется.
  Окно сохранения поддерживает отмену и подтверждение перезаписи.
  Пока окно открыто, помощник отвечает на запросы Studio о результате.
  Если порт занят, закройте предыдущий экземпляр помощника. При необходимости
  задайте -Port при запуске PS1 и тот же порт в HELPER_URL в Lua.
  Максимальный размер HTTP-запроса — 32 МБ.

Проверка:
  Сбор данных и выполнение командного скрипта проверены в Roblox Studio
  на временных объектах вне сцены. Объекты сцены и выделение не менялись.
  Проверены MeshPart, вложенные модели, повороты, PivotOffset, равномерный
  и разный по осям масштаб, пустой контейнер и ошибочное выделение.
  HTTP-обмен помощника проверен отдельно в PowerShell 5.1 и 7.
  Автоматический тест окна Windows недоступен в изолированном окружении;
  полный запуск Studio → окно сохранения нужно проверить при первом экспорте.
